# Как устроен Python CLI

## Аргументы и URL

`argparse` передаёт значение позиционного аргумента в `parse_target`. `urlsplit` выделяет схему, имя хоста, порт, путь и query. Проверки ограничивают схему HTTP и HTTPS и отклоняют встроенные в URL учётные данные. Замороженный `dataclass Target` хранит отдельно `request_path` с query для запроса и `display_url` с `?[redacted]` для экрана. `quote` кодирует нестандартные для URL символы в пути и query и сохраняет существующие `%`-последовательности. Фрагмент `#…` в запрос и вывод не попадает.

## Один GET

`download` создаёт `HTTPConnection` или `HTTPSConnection`. `time.perf_counter()` вызывается непосредственно перед `request("GET", ...)` и после EOF. Разность — секунды по монотонному таймеру. У HTTPS сертификат и имя хоста проверяются стандартным контекстом. `with connection.getresponse()` закрывает объект ответа и при успехе, и при исключении. `finally` закрывает соединение на обоих путях. [Документация `http.client`](https://docs.python.org/3.13/library/http.client.html), [документация `time.perf_counter`](https://docs.python.org/3.13/library/time.html#time.perf_counter).

В `while chunk := response.read(CHUNK_SIZE)` оператор `:=` присваивает очередной блок и одновременно проверяет, есть ли в нём данные. Счётчик растёт на `len(chunk)`. После пустого блока `response.length` помогает обнаружить преждевременный EOF при объявленном `Content-Length`. Для chunked-ответа границы блоков транспорта обрабатывает библиотека, а в объём входит содержимое тела. [Исходный код `HTTPResponse` в CPython 3.13.7](https://github.com/python/cpython/blob/v3.13.7/Lib/http/client.py).

## Цикл и статистика

`for` вызывает `download` на каждой попытке и ждёт возврата функции. Исключение переходит в `except`, затем `continue` запускает следующую попытку. Диагностика использует HTTP-код или категорию ошибки, поскольку сервер может включить query в текст статуса. При успехе складываются байты и секунды загрузки. Среднее — `total_seconds / successes * 1000`. Скорость — `total_bytes / total_seconds / 1048576`. Например, 1 MiB за 0.25 с и 0.5 MiB за 0.75 с дают 1.5 MiB/s за суммарную секунду.

## Тесты

`ThreadingHTTPServer` слушает loopback и задаёт отдельный ответ на каждый запрос. Таймер подменяется только в тесте формул, поэтому ожидаемые числа можно вычислить вручную. Тест порядка регистрирует вызовы настоящих `request` и `read` и проверяет чередование `GET`, `EOF` для десяти попыток. Тест таймаута удерживает соединение открытым после части тела и освобождает его через `threading.Event` при завершении.
