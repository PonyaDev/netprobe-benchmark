# NetProbe Benchmark

Черновик. CLI на Python и Node.js измеряют загрузку HTTP-ответов с текущей машины до выбранного сервера.

## Запуск

Команды запускаются из корня репозитория. Для Python нужен Python 3.10+, для JavaScript — Node.js 24+. Обе версии используют встроенные библиотеки.

```powershell
python python/netprobe.py 'http://127.0.0.1:8000/download'
python python/netprobe.py 'http://127.0.0.1:8000/download' --requests 3 --timeout 5
python python/netprobe.py --help
node node/netprobe.mjs 'http://127.0.0.1:8000/download'
node node/netprobe.mjs 'http://127.0.0.1:8000/download' --requests 3 --timeout 5
node node/netprobe.mjs --help
```

Подставьте URL доступного ресурса. По умолчанию обе версии выполняют 10 GET подряд и читают тело каждого 2xx до EOF. `--timeout` задаётся в секундах, значение по умолчанию — 10. Поддерживаются HTTP и HTTPS со штатной проверкой TLS. Query передаётся серверу и скрывается в выводе CLI. URL со встроенными учётными данными отклоняются. Ответы 3xx, 4xx и 5xx учитываются как ошибки.

Код выхода `0` означает хотя бы один успех, `1` — ни одного, `2` — ошибка аргументов. При сбое CLI печатает номер попытки и причину в `stderr` и переходит к следующей. Учитываются только полностью прочитанные успешные ответы.

## Что измеряется

Время включает отправку GET, ожидание ответа, чтение тела и открытие соединения, если оно новое. CLI выводит число успехов и ошибок, среднее время в ms, сумму прочитанных байтов в MiB и скорость в MiB/s. Скорость равна сумме успешных байтов, делённой на сумму времени тех же попыток в секундах и на 1 048 576. Показатель зависит от адреса, маршрута, сервера и клиента.

Python использует `http.client`, читает блоками по 64 КиБ и явно закрывает соединение после каждой попытки. Таймаут ограничивает блокирующие операции сокета. Разрешение DNS и длительная передача с регулярным поступлением данных могут занять больше указанного времени.

Node.js использует встроенный `fetch` на Undici. Повторное использование соединений — часть работы клиента. Один таймаут охватывает ожидание ответа и чтение тела. `fetch` отдаёт распакованные данные при поддерживаемом `Content-Encoding`, а Python считает байты в представлении, полученном от сервера. Для сравнения клиентов используйте ресурс без сжатия и учитывайте политику соединений. [Документация Undici](https://undici.nodejs.org/#undici-vs-fetch).
