# NetProbe Benchmark

Черновик. Python CLI измеряет загрузку HTTP-ответов с текущей машины до выбранного сервера.

## Запуск

Из корня репозитория с Python 3.10+.

```powershell
python python/netprobe.py 'http://127.0.0.1:8000/download'
python python/netprobe.py 'http://127.0.0.1:8000/download' --requests 3 --timeout 5
python python/netprobe.py --help
```

Подставьте URL доступного ресурса. По умолчанию CLI выполняет 10 GET подряд с таймаутом сокета 10 секунд. Для каждого 2xx он читает тело до EOF блоками по 64 КиБ в памяти. Каждый запрос открывает новое соединение, HTTPS использует стандартную проверку сертификата и имени хоста, query скрывается в выводе.

Код выхода `0` означает хотя бы один успех, `1` — ни одного, `2` — ошибка аргументов. При сбое CLI печатает номер попытки и причину в `stderr` и переходит к следующей. Учитываются только полностью прочитанные успешные ответы.

## Что измеряется

Время включает открытие соединения, отправку GET, ожидание ответа и чтение тела. CLI выводит число успехов и ошибок, среднее время в ms, сумму прочитанных байтов в MiB и скорость в MiB/s. Скорость равна сумме успешных байтов, делённой на сумму времени тех же попыток и на 1 048 576. Показатель зависит от адреса, маршрута, сервера и клиента.

Выбран `http.client` из стандартной библиотеки. С ним потоковое чтение, отдельное соединение на попытку и обработка статусов видны прямо в коде. Клиент работает поверх HTTP/1.1, подключается напрямую и завершает попытку с ошибкой при ответе 3xx. Таймаут применяется к блокирующим операциям сокета. Разрешение DNS и длительная передача с регулярным поступлением данных могут занять больше указанного времени.

## Локальная проверка

```powershell
python -B -m unittest discover -s python -v
```

Тесты используют локальный mock на `127.0.0.1` с автоматически выделенным портом. Пробный запуск 16.11.2026 на Windows 11 и Python 3.13.7 измерил `http://127.0.0.1:56372/download?[redacted]`. Результат — 1 успех, 0 ошибок и 1 MiB за 14.884 ms (67.188 MiB/s). Порт и показатели времени меняются от запуска к запуску.
